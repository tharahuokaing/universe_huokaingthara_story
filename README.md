## 🎯 About the Platform / អំពីវេទិកា

**UNIVERSE HUOKAING THARA Story Platform** is a dedicated literary and biographical portal designed to publish inspirational narratives, historical essays, strategic vision articles, and traditional Cambodian folklore under the leadership of **Huokaing Thara**.

## ✨ Key Features / លក្ខណៈពិសេសចម្បង

* **🔍 Live Article Filtering:** Real-time search functionality allowing readers to instantly locate specific topics, titles, or authors across the archives.
* **🌐 Dual Language Support:** Instant toggle between **Khmer (ខ្មែរ)** and **English** interface presentations.
* **🌙 Dark/Light Theme Switcher:** Fully customizable visual styling featuring a cyberpunk holographic scanline overlay.
* **⚡ Responsive Grid Architecture:** Clean, distraction-free reading layouts optimized for mobile phones, tablets, and desktop displays.

## 🛠️ Tech Stack & Architecture / បច្ចេកវិទ្យាប្រើប្រាស់

- **Frontend:** HTML5, CSS3 (CSS Grid & Custom Properties), JavaScript (ES6+)
- **Typography:** Google Fonts (`Kantumruy Pro`, `Poppins`)
- **Icons:** FontAwesome v6.4.0
- **Aesthetic:** Cyberpunk Holographic Dark/Light Theme with Scanlines

## 🚀 Getting Started / ការចាប់ផ្តើម

To run this repository locally on your machine:

1. **Clone the repository:**

git clone [https://github.com/your-username/universe-huokaingthara-story.git](https://github.com/your-username/universe-huokaingthara-story.git)

2. **Navigate to the project directory:**

cd universe-huokaingthara-story

3. **Open `index.html**` in any modern web browser or run it via VS Code Live Server.
